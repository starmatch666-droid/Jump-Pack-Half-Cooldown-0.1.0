# 喷射背包：冷却减半

仅修改玩家使用的喷射背包（跳跃背包）。

- 冷却时间：15 秒 → 7.5 秒。
- 起跳力度、滞空控制和落地保护保持原版。
- 不修改悬浮背包或其他喷射单位。

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

导入本包到 Arsenal / HD2 Mod Manager，启用后部署。Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 适配游戏构建 **25327279**。
- 运行时写入与回读已验证。
- 内存模组属客户端改动，联机表现可能不一致。

## 日志

```
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\JumpPackHalfCooldown.log
```

写入成功会记录 `applied_template_gameplay_unverified`；数据不匹配时记录 `*_not_write` 并**拒绝写入**，不会强行覆盖。

## 注意

- 内存模组属**客户端运行时改动**：只在本次游戏会话内生效，退出游戏即恢复原状。
- 联机表现可能与队友不一致，并存在**反作弊风险**。建议仅在知情固定队环境中使用。
- 卸载：用管理器禁用本包并重新部署；手动安装需保持 `patch_N` 编号连续，**不要直接删除中间编号的文件**。
